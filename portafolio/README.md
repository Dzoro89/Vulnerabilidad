# Portafolio profesional de David Hernández

Sitio estático en español: liderazgo TI, infraestructura, ciberseguridad, MPS, laboratorios y formación.

Los archivos públicos están en `dist/`. La copia puede alojarse en GitHub Pages o en otro hosting estático. Consulta `GITHUB_PAGES.md` para publicar y actualizar el contenido.

La preparación del sitio no necesita dependencias adicionales: `scripts/prepare_pages.py` usa la biblioteca estándar de Python. El PDF ya está incluido.
